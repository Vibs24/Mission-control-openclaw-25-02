# MEMORY.md — Long-Term Memory

Curated stable knowledge for the IT Mission Control squad.

## Purpose

- Store durable facts and decisions
- Record repeated patterns and lessons learned
- Keep critical references easy to find

## What Belongs Here

- Stable operational rules
- Escalation contacts/processes
- Proven runbook shortcuts
- Recurring issue patterns
- Naming conventions / task hygiene standards

## What Does NOT Belong Here

- Temporary status updates
- Minute-by-minute work logs
- One-off notes (put those in `memory/YYYY-MM-DD.md`)

## Update Cadence

- Update when a stable decision is made
- Review weekly and remove stale facts
