# life/ (PARA Knowledge Graph)

This is the canonical PARA memory root for Mission Control.

- `projects/` active outcomes and deliverables
- `areas/` ongoing responsibilities and entities (people/companies)
- `resources/` reusable references
- `archives/` inactive entities

Entity contract:
- `summary.md` hot/warm synthesized context
- `items.json` full atomic facts (no deletion; supersession only)

State:
- `.state/pkm-checkpoint.json`
- `.state/pkm-metrics.json`
