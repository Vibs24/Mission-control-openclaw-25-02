# Podcast Repurposing Studio MVP — Product Spec

## Goal
Turn one podcast transcript into publish-ready content for X, LinkedIn, newsletter, YouTube metadata, and short-form clip hooks.

## Inputs
- Episode title
- Guest name
- Full transcript (required)
- Optional URL

## Outputs
- 10 X posts (hook-first)
- 3 LinkedIn posts
- 1 newsletter draft
- YouTube package:
  - 3 title options
  - Description
  - Timestamps
  - 15 tag ideas
- 10 short-form clip hook ideas

## Utility Features
- Copy currently selected tab section
- Download all outputs as one markdown file
- Save/load latest session locally (browser localStorage)

## Non-Goals
- No external posting or email sending
- No remote persistence/backend DB
