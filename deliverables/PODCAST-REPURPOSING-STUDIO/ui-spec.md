# UI Spec

## Layout
- Two-column desktop layout:
  - Left: Input panel
  - Right: Output tabs and actions
- Single-column mobile layout (<900px)

## Input Panel
- Text inputs: episode title, guest name, optional URL
- Large textarea for transcript
- Buttons: Generate, Save Local, Load Local

## Output Panel
- Tabs: X, LinkedIn, Newsletter, YouTube, Clip Hooks
- Actions row: Copy Section, Download Markdown
- Preformatted output viewport with scroll

## UX Requirements
- Generate validates transcript presence
- Active tab state visible
- Local session auto-load on page refresh
