# PulseDesk Component Library
Theme: dark charcoal + electric blue (#111827 / #3B82F6)

## Foundations
- Typography: Inter + geometric fallback
- Spacing scale: 4/8/12/16/24/32
- Radii: 8, 12

## Components
- TicketCard (priority dot, overdue state, assignee avatar, comment badge)
- KanbanColumn (accent header + ticket count badge)
- AgentChatPane (thread + composer)
- NotificationBellPanel (layered list)
- SearchInput (live filter)
- AnalyticsMetricCard
- SLAChart (Recharts line/bar)
