# Simple Mission Status Dashboard (HTML/CSS)

A small static dashboard with KPI cards and a mission status table.

## Files
- `index.html` — dashboard UI
- `styles.css` — styling
- `sample-data.js` — sample KPI + table data

## Run Locally
Option 1 (open directly):
- Open `index.html` in your browser.

Option 2 (simple local server):
```bash
python3 -m http.server 8080
```
Then visit: `http://127.0.0.1:8080`
